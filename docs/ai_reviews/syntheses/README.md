# Multi-Model AI Review Syntheses

> **Directory Purpose:**  
> This directory archives structured cross-model synthesis reports comparing, reconciling, and auditing the outputs of multiple frontier AI models evaluating the same research question.

---

## Operating Protocol

1. **Synthesis Prerequisite:** A synthesis report should be drafted only after two or more independent AI model reviews have been conducted and archived in `docs/ai_reviews/independent_reviews/`.
2. **Template Adherence:** All synthesis reports must use [docs/templates/AI_REVIEW_SYNTHESIS_TEMPLATE.md](../../templates/AI_REVIEW_SYNTHESIS_TEMPLATE.md).
3. **Naming Convention:**  
   `SYNTHESIS_<TASK_ID>_<TOPIC>_<YYYYMMDD>.md`  
   *(Example: `SYNTHESIS_M01_CGGA_VALIDATION_FEASIBILITY_20261114.md`)*
4. **Epistemic Discipline:**
   - Clearly delineate where independent models reached genuine scientific consensus vs where they exhibited shared superficial heuristics.
   - Highlight material disagreements.
   - Distinguish claims backed by primary sources from speculative model assertions.
   - Formulate concrete decision proposals for human supervisor review.
5. **No Automatic Adoption:** Synthesis recommendations remain strictly advisory until reviewed and approved by the human supervisor.
