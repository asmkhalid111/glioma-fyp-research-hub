# Incoming AI Review Staging Area

> **Directory Purpose:**  
> This directory serves as a temporary staging drop-box for unreviewed, raw AI model review outputs generated across external platforms (T3 Chat, ChatGPT, Claude, Gemini, etc.).

---

## Operating Protocol

1. **Drop Raw Output:** Immediately paste or save the raw text output from an external AI model here using the naming format:  
   `RAW_<TASK_ID>_<ROLE>_<PROVIDER_MODEL>_<YYYYMMDD>.md`  
   *(Example: `RAW_M01_METHODOLOGICAL_CLAUDE-3.5-SONNET_20261114.md`)*
2. **Do Not Treat as Evidence:** Files in this directory are completely unvetted. They must never be cited or relied upon as approved research findings.
3. **Audit Before Archiving:** Before moving to `independent_reviews/`:
   - Fill out [docs/templates/AI_REVIEW_RECORD_TEMPLATE.md](../../templates/AI_REVIEW_RECORD_TEMPLATE.md).
   - Check citations against primary literature.
   - Categorize into the appropriate review folder (`scientific/`, `methodological/`, etc.).
   - Delete or archive the raw incoming file once the permanent record is filed.
